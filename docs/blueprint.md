# **App Name**: Florarte Landing

## Core Features:

- Display Floral Arrangements: Dynamically render floral arrangement catalog using data from products.js.
- WhatsApp Order: Implement WhatsApp direct order functionality with pre-filled message.
- Mobile-First Design: Optimize layout and responsiveness for mobile devices.

## Style Guidelines:

- Primary color: Rose-red (#F42559) for love and passion.
- Background color: Light rose (#F8F5F6) for a soft, elegant feel.
- Accent color: Similar dark pink shade, like cranberry (#D81B4D), for complementary calls to action and gradient.
- Body and headline font: 'Plus Jakarta Sans' (sans-serif) for modern, clean look. Note: currently only Google Fonts are supported.
- Use Material Symbols Outlined for clear and modern icons.
- Mobile-first, responsive layout with clear sections and spacing.
- Subtle hover animations on product cards and buttons to enhance interactivity.
